# Real-phone test (about 30 minutes)

Use the installed app (Add to Home Screen) on your phone, on mobile data, not Wi-Fi.
Tick each line; write down anything slow, ugly or confusing, with a screenshot.

**First run**
- [ ] Open https://ofekbp.github.io/globefolio/ . Skeleton appears, then the globe. Feels fast?
- [ ] Add to Home Screen; open from the icon; no browser bar.
- [ ] Welcome screen in your language; switch language in Settings and back.

**Without an account**
- [ ] Add a trip (search a city, pick dates, save). Passport stamp appears.
- [ ] Turn on airplane mode, close and reopen the app: still opens, map and trip still there.

**Account**
- [ ] Sign in with Google. Handle screen appears once; pick a handle.
- [ ] Sign out; sign in with the email link (check inbox and spam; link opens the app and signs you in).
- [ ] Your earlier local trip is now in the account.

**Two devices**
- [ ] Second device (or a browser): sign in, see the same trips. Add one on A; it shows on B within seconds.

**Friends**
- [ ] Second account: send a friend request by handle, accept, see the friend's globe, Block, Unblock, Report (a message is sent).

**Shared trip**
- [ ] Create a shared trip, invite the friend, both add stops, both see changes live.

**Look and feel**
- [ ] Dark mode, Hebrew or Arabic (right-to-left), large text size in phone settings. Nothing cut off.
- [ ] Delete the test account in Journal > Your account (confirms data is gone).

Send me the list of problems. Crash reports appear in Supabase > Table Editor > `error_reports`.
